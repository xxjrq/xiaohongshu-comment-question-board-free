# Xiaohongshu Comment Question Board

Turn up to 20 currently visible comments from one user-specified Xiaohongshu note into a traceable reader-question board: categories, counts, and the visible position of every source comment. It is for topic research and content-gap discovery, and never invents questions or counts when comments are absent or inaccessible.

Input: one note page and one user-provided `browserId`.

Output: categorized questions, frequencies, per-comment visible source positions, and a clear list of missing information or an `uncollectable` result.

## Install

```bash
npx skills add xxjrq/xiaohongshu-comment-question-board-free
```

This browser Skill requires [Easy WebBridge on GitHub](https://github.com/xxjrq/easy-webbridge), with [Gitee](https://gitee.com/xxjrq/easy-webbridge) as a fallback. Select exactly one supplied browserId per run; create and close only the task-owned session and tab group.

The workflow is read-only by default. It reads only visible page material, refreshes references after scrolling, stops for login, CAPTCHA, risk controls, or security verification, and never bypasses them. Draft filling, if explicitly authorized, must never click final publish or send.

## Offline verification

```bash
node scripts/self-test.mjs
```

Fixtures simulate offline page material and are not live collection results.
